# 常见陷阱与恢复路径

先识别症状，再停在最接近故障的层级。不要因为局部异常就整体重做，也不要用增加参数或继续生成素材掩盖上游错误。

| 症状 | 首查对象 | 停止点 | 恢复路径 |
| --- | --- | --- | --- |
| 白色椭圆边、棋盘格或画布透出 | `static_locked_base` 是否挖空；状态层 Alpha 是否覆盖洞 | PSD/Cubism 继续操作 | 恢复全脸非空底图，重新跑 Alpha 覆盖与蒙版外 diff |
| 半态重影、嘴角双层或眼皮闪变 | 是否用极端图交叉淡化；half donor 是否独立 | 不进入参数平滑优化 | 制作独立 half 状态，重建联系表和局部层 |
| 颜色/光照/脸型突然变化 | 是否直接使用整脸生成输出；蒙版外 diff | 丢弃该 donor，不扩大编辑范围 | 从原图恢复蒙版外像素，仅保留局部 donor |
| PSD 导入拒绝或读取越界 | 通道压缩、位深、Alpha、Cubism 版本 | 停止反复试编码 | 保留透明 PNG 权威源，改用已实机验证的兼容编码或人工组装 |
| 默认显示闭眼张嘴或极端混合 | 图层名是否重复；全层初始可见顺序；默认层透明度 | 不开始参数绑定 | 逐层核对十层名称和中性默认画面，再重建 manifest |
| 拖嘴时眼睛变化，或单眼影响另一眼 | 绿色关键点是否绑错参数；参数 ID 与 viewer-left/right 是否混淆 | 立即停止综合验收 | 删除错误绑定，按层逐项重绑并单参数拖动复验 |
| 某个参数节点没有保存或重开后回退 | 是否另存到正确的新文件；节点是否实际写入当前模型 | 不导出、不进前端 | 保留最后通过的检查点，确认标题栏/路径后重新保存并重开 |
| 视觉异常只在小屏出现 | 缩放、边缘羽化、ROI 过小或接缝放大 | 暂停增加动作 | 在目标 320–430 CSS px 预览联系表，先回修局部 Alpha/边缘 |

## 处理顺序

1. 记录当前参数值和症状，不继续拖动。
2. 只检查当前区域：参数绑定→节点透明度→绘制顺序→PSD Alpha/像素。
3. 若输入契约、全脸底图或蒙版外差异不满足，回到输入/PSD 层，不在 Cubism 中补洞。
4. 若规则冲突，暂停 tracker，回到规则登记表和诊断，必要时重新规划。
5. 修复后重跑当前区域的定点、往返和组合验收，再恢复串行流程。

## 明确禁止

- 不用挖空底图修补透明洞。
- 不把默认重复局部层设为常驻 100%。
- 不用整脸 AI 输出替换原图。
- 不批量复制层名、参数或节点而不逐项核对。
- 不把“看起来正常”当作重开持久性证据。
