# Cubism 手工建模参考

本参考假定 PSD 已通过输入、Alpha、图层名和蒙版外像素闸门。它只描述用户在 Cubism Editor 中的可复用操作顺序；自动脚本不能代替画布自然度判断。

## 导入与属性核对

- 确认 `static_locked_base` 是完整全脸、非空、全不透明原图。
- 确认十个状态层全画布、独立命名、同一尺寸/原点，默认初始全层可见时是闭嘴双眼睁开的中性画面。
- 逐层确认名称、画布位置、尺寸、Alpha Blend=Over、无剪贴、无反转蒙版。
- 确认静态底图未绑定参数；状态层绑定到预期的嘴或对应 viewer-left/viewer-right 眼参数。
- 先取消对象选择、移开鼠标和工具轮廓，再确认初始中性画面没有白边、破洞或重复覆盖。

## 参数设置

- `ParamMouthOpenY`：范围 0..1，默认 0；0 闭嘴，0.5 半张嘴，1 张嘴。
- `ParamEyeLOpen`：范围 0..1，默认 1；0 viewer-left 闭眼，0.5 半闭，1 睁眼。
- `ParamEyeROpen`：范围 0..1，默认 1；0 viewer-right 闭眼，0.5 半闭，1 睁眼。

遵循 [PSD 与 Cubism 层/参数契约](psd-layer-contract.md) 的覆盖表：底图 400；局部默认/半态/终态层使用 500/510/520 的绘制顺序样例。

- 底图永久 100%；`mouth_closed_local`、`eye_L_open_local`、`eye_R_open_local` 在所有关键点为 0%。
- 嘴半/开和眼半/闭使用累积覆盖；不要把默认层重新设为常驻 100%。
- 设置一个区域时，另外两个参数保持默认值；设置后立即拖动当前参数确认只有目标区域变化。
- 检查参数绑定时同时看参数名称、节点位置、图层名称和绿色关键点。

## 分区操作与检查点

按嘴→viewer-left 眼→viewer-right 眼的顺序，一次只处理一个区域：

1. 在 0、0.5、1 建立关键点和透明度；再检查 0.3、0.8。
2. 缓慢往返拖动 0→1→0，观察连续性和独立性。
3. 取消选择后检查白边、透明破洞、重影/双影、硬矩形接缝、色温跳变、突然换皮。
4. 通过后用新文件名另存该区域检查点；关闭并重开检查点，确认默认值和节点没有丢失。
5. 任一异常只回查当前区域的参数绑定、透明度节点、绘制顺序和 PSD Alpha。

## 综合验收

至少检查默认、嘴半/开＋双眼睁开、闭嘴＋双眼闭合、嘴开＋双眼闭合、嘴 0.8/左眼 0.3/右眼 0.3，以及分别拖动三个参数时其他区域不动。最后另存最终 `.cmo3`，关闭并重开，复测默认值、关键点、往返拖动和组合状态。
