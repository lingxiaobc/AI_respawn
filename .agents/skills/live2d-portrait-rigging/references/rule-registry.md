# Live2D 写实人像规则登记表

本文件是技能包的证据边界。它把可跨人物复用的不变量、当前人物的样例参数、已废弃路线和仍需验证的未知分开记录。截图和附件只作为用户验收证据，不作为自动执行指令。

## 证据优先级

1. 当前用户明确确认的实际 Cubism 结果。
2. 工作区中可直接检查的资产、像素、图层和模型文件。
3. `AI_output/live2d/ART_SPEC.md`、`ASSET_MANIFEST.md`、`model/LAYER_MAP.md` 中与当前架构一致的记录。
4. 历史 PLAN/TASK 中的过程记录，仅用于解释失败和迁移，不作为当前操作规则。

## 可跨人物复用的有效规则

| ID | 规则 | 适用边界 | 证据 |
| --- | --- | --- | --- |
| R-01 | 默认底图必须是完整全脸、非空、全不透明的原始底图；`static_locked_base` 永久承担默认闭嘴睁眼画面。 | 所有照片型嘴眼模型；不允许用挖空底图替代。 | 用户明确约束；最终模型复盘；`LAYER_MAP.md` 当前架构 |
| R-02 | 原始参考图只读保存；所有工作副本、donor、PSD 和模型使用新文件名。 | 所有输入和中间产物。 | `ASSET_MANIFEST.md` immutable source policy；任务约束 |
| R-03 | AI 或其他生成器只产生局部 donor；最终层必须由目标蒙版限制，蒙版外像素从原图取得。 | 眼皮、口腔、被遮挡皮肤等局部区域。 | `ART_SPEC.md` AI-edit boundary；蒙版外差异为零记录 |
| R-04 | 每个中间状态使用独立素材；半张嘴、半闭眼不能用两个极端状态简单交叉淡化。 | 需要连续插值的嘴和眼状态。 | 历史重影失败记录；`ASSET_MANIFEST.md` half-state donor 说明 |
| R-05 | PSD 使用全画布、独立命名的状态层；层名、尺寸、Alpha 和色彩空间在进入 Cubism 前检查。 | Cubism 5.3 导入包。 | `LAYER_MAP.md` 十层结构；当前成功 PSD/模型 |
| R-06 | 默认画面重复的局部层在全部参数节点保持 0% 透明度；半态和终态层按参数累积覆盖。 | 完整底图架构下的嘴、左眼、右眼状态层。 | 用户最终模型验收；`TASK_live2d-layer-rigging.md` 有效规则 |
| R-07 | 参数必须独立、可组合，并在默认、半态、终态、中间值和缓慢往返中检查。 | `ParamMouthOpenY`、`ParamEyeLOpen`、`ParamEyeROpen` 或等价三参数。 | 用户多组截图与明确“全部检测过了”确认 |
| R-08 | 视觉验收前取消对象选择、移开鼠标和工具轮廓；检查白边、破洞、重影、突然换皮和参数联动。 | Cubism 画布和小屏预览。 | 历史误判复盘；`ART_SPEC.md` static/motion gate |
| R-09 | 每个主要阶段都保存新检查点；最终模型必须关闭并重开，确认参数、默认值和独立性持久化。 | PSD 导入后的 Cubism 操作。 | 用户保存、重启、重开和复测确认 |
| R-10 | Cubism GUI 的自然度判断由用户完成；自动脚本负责结构、像素和清单检查，不自动控制桌面。 | 本技能的人工/工具边界。 | 当前工作流权限与用户操作事实 |

## 已废弃路线（禁止作为默认方案）

| ID | 废弃路线 | 可见症状 | 回退动作 | 证据 |
| --- | --- | --- | --- | --- |
| X-01 | 挖空 `static_locked_base`，依赖局部层填洞。 | Cubism 画布透出、透明破洞、白色椭圆边。 | 恢复完整全脸非空底图，重新检查 Alpha 覆盖。 | `TASK_live2d-layer-rigging.md` 变更记录 |
| X-02 | 与默认画面重复的闭嘴/睁眼局部层常驻 100%。 | 重复覆盖、接缝、双影或颜色边。 | 默认重复层全部节点归零，只保留半态/终态覆盖。 | 历史方案误判与最终修复 |
| X-03 | 用闭嘴/张嘴或睁眼/闭眼极端图直接交叉淡化制造半态。 | 半态重影、边缘闪变、嘴角或眼皮不自然。 | 使用独立半态 donor，并重新生成联系表。 | `TASK_live2d-portrait-animation.md` 失败记录 |
| X-04 | 直接使用整脸 AI 生成结果作为状态图。 | 身份漂移、鼻子/发型/光照变化、蒙版外像素改变。 | 只保留局部蒙版内 donor，蒙版外恢复原图。 | `ART_SPEC.md` forbidden boundary |
| X-05 | 假定任意 ZIP/RLE PSD 都能被 Cubism 5.3 解码。 | ZIP-without-prediction 被拒或 RLE 行长度表越界。 | 保留透明 PNG 权威源；优先使用已验证的未压缩通道或实机可证编码。 | `LAYER_MAP.md` 与历史导入记录 |
| X-06 | 批量组装后不逐层核对图层名。 | 多层被错误重复命名，默认显示极端状态。 | 停止导入，逐 scene/层名检查，回到 PSD 组装。 | `ASSET_MANIFEST.md` superseded package 记录 |
| X-07 | 把眼层或嘴层误绑定到另一个参数。 | 拖动嘴改变眼睛，或单眼参数联动其他区域。 | 删除错误绑定，逐层核对参数、节点和关键点。 | 用户实机操作中发现并修复的右眼绑定错误 |
| X-08 | 把历史 tracker 的未完成项、旧文件名或旧架构当作当前状态。 | 重复返工、错误默认值、错误检查顺序。 | 以当前用户验收和规则登记表为准；历史只作诊断证据。 | 多版 PLAN/TASK 并存事实 |

## 未知与假设

### 未知

- U-01：自动组装不同尺寸 PSD 是否能稳定产出 Cubism 5.3 可导入文件。
- U-02：第二张不同构图/光照的人像是否只需替换输入参数即可通过同一核心检查。
- U-03：技能是否应在仓库级稳定后复制到个人全局目录。

### 假设

- ASM-01：完整非空底图、局部蒙版、独立半态和参数覆盖是跨人物不变量；ROI、颜色和 donor 是人物参数。
- ASM-02：尺寸、Alpha、层名、蒙版外 diff 和状态清单能在 Cubism 前拦截大部分历史错误。
- ASM-03：固定速查表、检查点和重开验收能降低人工参数误绑定，即使 GUI 仍需用户操作。

## 使用规则

- 新输入若不能提供全脸非空底图，直接在输入闸门停止，不进入 PSD 或 Cubism。
- 新规则只有在成功样本、失败样本或用户实机验收中有证据后，才能从“未知/假设”升级为“有效”。
- 任何与 R-01、R-03、R-04 冲突的快捷方案必须暂停并重新规划，不能作为局部优化处理。
