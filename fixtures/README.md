# Test audio fixtures

`input/test-utterance.wav` is built from three samples in the Free Spoken Digit Dataset (FSDD):

- `0_jackson_0.wav`
- `1_jackson_0.wav`
- `2_jackson_0.wav`

Source: https://github.com/Jakobovski/free-spoken-digit-dataset

License: Creative Commons Attribution-ShareAlike 4.0 International. The source files are resampled from 8 kHz PCM16 mono to 16 kHz PCM16 mono and separated by 250 ms of silence solely as a deterministic provider-integration fixture.
