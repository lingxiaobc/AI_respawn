## 发现与边界

持续不发语音、仅发送“继续通话”的长连接，在约11分钟收到豆包 `55000000 / Abnormal silence audio`，随后应用正确结束并释放。改用每分钟公开测试语音后，15分钟真实时间验证通过。15轮从提交到网关收到首段音频为779—1506ms，尚未包含浏览器/WASM播放启动及设备延迟，不等于耳听首声延迟。

浏览器采样检测到嘴部变化，但部分轮次变化帧占比偏低，一轮最大调度间隙约16ms。页面可见性和浏览器节流会影响渲染；这些数字不能代替听感、连续流畅度和嘴型同步的人工判断。

Windows 父进程句柄监测避免 PID 复用误判，只停止该人物处理进程树；它仍依赖工作进程能运行监测线程及系统停止命令成功，不能承诺对任意系统/驱动级死锁都立即回收。正常通话抢占若停止失败，服务阻止新通话和制作，并明确提示重启。

性能对照中网关CPU累计增量分别234/78ms，工作集从145965056到79233024字节、从80384000到82247680字节。回复音频分别394950/191598字节，样本仅各一次且有冷暖状态差异，不能直接据此宣称两种情况性能相同或计算统计分位数；测量不包含浏览器WASM、GPU和物理扬声器延迟。制作进程归零证明已让出其计算资源。
