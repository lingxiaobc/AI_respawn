# 任务跟踪：修复实时语音尖刺杂音

## 任务目标与批准快照

- 目标：修复豆包实时语音 Demo 的尖刺杂音，建立唯一的 Float32LE→PCM16LE provider 音频边界，并重新验证正常人声闭环。
- 主要诊断：模型输出事件已到达，但服务端音频编码/位深与客户端 PCM16 假设不一致，导致每个真实样本被拆成两个 Int16 值。
- 指导方针：以单一 provider 音频规范化边界为修复中心，先修格式再修播放；验收必须同时有事件、波形和人工听感证据。
- 近端目标：一次最小真实探针产出 24 kHz 单声道 PCM16LE，随后完成 5 轮浏览器听感确认。
- 主动不做：不换模型、不改输入或会话状态机、不做 Avatar、声音复刻、RAG、部署或全双工。
- 批准依据：用户已明确批准 `PT-ai-respawn-ptt-demo v2` 全部五个步骤，并授权一次最小真实模型复测。
- 路由快照：auto / 标准风险 / 混合可逆性 / M-01,M-02,M-03,M-05,M-07,M-08。
- 已选模块：M-01,M-02,M-03,M-05,M-07,M-08。
- 用户步骤映射：S-01 -> A-01,A-02; S-02 -> A-03; S-03 -> A-04,A-05; S-04 -> A-06,A-07; S-05 -> A-08,A-09,A-10
