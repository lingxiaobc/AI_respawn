# 任务方案：DH_live_mini 固定人物接入与测试
## 任务事实与边界
REQ-01：用户明确要求采用第一推荐开发测试，并新建分支。
F-01：新分支codex/dh-live-mini，基于codex/option2-APIcall。未跟踪PRD保留不修改。
F-02：既有豆包网关输出24kHz PCM16LE；浏览器WebAudio调度。
C-01：本轮仅固定示例人物、自然嘴型；不做管理员自动创建、购买和部署。
U-01：上游WASM音频接口、资源和实际效果待验证。
ASM-01：先用上游公开示例人物保留标识。

## 关键挑战诊断
D-01：豆包流与上游音频队列/嘴型时钟的接口不一致会导致串轮或不同步；必须验证真实推理输出而不只播放底板视频。
ALT-01：资源或浏览器不兼容使渲染无法启动；最小页面区分资源问题与音频桥接。
支持链：F-02与U-01。嘴型不能受音频驱动则推翻本路线可用判断。
