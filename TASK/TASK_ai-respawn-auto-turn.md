# 任务跟踪：自动静音判停语音对话

## 任务目标与批准快照

- 目标：移除 PTT 按钮和空格键，以“有效讲话 + 连续 1200 ms 静音”自动提交模型回复，并在播放完成后重新监听。
- 主要诊断：现有 Demo 把轮次结束绑定在 DOM 按钮事件；撤掉按钮后必须先建立独立、可测试的判停状态机并与既有网关状态交接。
- 指导方针：以浏览器侧可测试判停器和现有内部网关轮次协议为核心，按“判停逻辑 → 自动采音 → 半双工重启 → UI/文档 → 验证”串行推进。
- 近端目标：本机 Chrome 至少完成一轮“说话 → 1.2 秒静音 → 自动回复 → 播放结束后重新监听”，并通过离线边界测试。
- 主动不做：语义判停、插话、全双工、AEC、RAG、长期记忆、头像/嘴型、移动端、公网部署和供应商替换。
- 批准依据：用户已批准 `PT-ai-respawn-auto-turn v1` 全部五个可见步骤。
- 路由快照：auto / 标准风险 / 混合可逆性 / M-01,M-02,M-03,M-05,M-07,M-08。
- 已选模块：M-01,M-02,M-03,M-05,M-07,M-08。
- 用户步骤映射：S-01 -> A-01; S-02 -> A-02,A-03; S-03 -> A-04; S-04 -> A-05,A-06; S-05 -> A-07,A-08
