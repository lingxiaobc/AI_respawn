# TASK 归档说明

`TASK/archive/` 是任务文档的可逆归档区：

- `completed/`：已经通过验收或由用户明确确认完成的里程碑。
- `superseded/`：暂停、被新版本替代或仅作历史参考的路线。
- `ARCHIVE_INDEX.md`：唯一索引，记录原文件、分类依据、最终位置和当前活动入口。

本次 Live2D 前置关闭依据是用户最终确认和已保存、重启后复核正常的模型资源；旧的细项 tracker 原文仍保留在 `completed/`，另附完成摘要。Live2D 与前端结合尚未开始，仍由 `TASK/` 根目录中的活动计划跟踪。

归档操作只移动/复制 Markdown 文档，不删除任何历史、模型、PSD、源图、技能资产或代码。
