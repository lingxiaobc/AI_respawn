# TASK：Live2D 嘴部与眼部动画

## 任务目标与批准快照

- 目标：以用户提供的正脸照片制作移动端小屏 Live2D 嘴部开合与双眼眨眼模型，并让现有豆包实时语音的实际播放音频驱动嘴部幅度。
- 主要诊断：原照片缺少张嘴、闭眼后会暴露的口腔、眼皮和隐藏皮肤像素；美术底板是会被下游建模与代码放大的首要弱环。
- 指导方针：原图拆层、目标区域局部补绘、静态极限状态先验收；身份一致性和可回退性优先于动作数量和写实程度。
- 近端目标：完成一个可本地运行的移动端嘴眼 Stage 0，三项标准参数、局部 AI、不破坏现有语音链，并通过构建与回归测试。
- 主动不做：整脸重绘、多张完整状态脸、真人视频、音素级口型、头动、视线、复杂表情、生产部署和商用许可签署。
- 批准依据：用户于 2026-08-31 在确认移动端小屏、AI 动画预期、禁止整脸重绘和肖像权边界后明确表示“全部批准并执行”。
- 路由快照：因果不确定性中高；美术→建模→运行时→音频同步为强依赖链；风险标准；不可逆性混合；中等跨工具协调。
- 已选模块：M-01,M-02,M-03,M-04,M-06,M-07,M-08。
- 用户步骤映射：S-01 -> A-01; S-02 -> A-02,A-03,A-04; S-03 -> A-05; S-04 -> A-06,A-07; S-05 -> A-08; S-06 -> A-09
